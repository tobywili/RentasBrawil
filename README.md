# Rentasbrawin - sitio web

Sitio estático creado con HTML y CSS.

## Archivos
- `index.html`: contenido de la página.
- `css/styles.css`: diseño y estilos.
- `img/`: carpeta para agregar fotografías propias de las motos.

## Antes de publicar
1. Revisar los dos números de WhatsApp del archivo `index.html`.
2. Reemplazar los bloques "AGREGAR FOTO DE LA MOTO" por fotografías propias.
3. Completar o corregir los requisitos y condiciones reales del alquiler.

## Publicar gratis con GitHub Pages
1. Crear una cuenta en https://github.com/ si todavía no tenés.
2. Crear un repositorio nuevo, por ejemplo `rentasbrawin`.
3. Subir `index.html`, la carpeta `css` y el resto de archivos.
4. En el repositorio entrar en **Settings → Pages**.
5. En **Build and deployment**, elegir **Deploy from a branch**.
6. Elegir la rama `main` y la carpeta `/ (root)`, guardar.
7. GitHub mostrará la dirección pública del sitio cuando termine la publicación.
